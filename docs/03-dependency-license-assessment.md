permissive licences are adopted; copyleft needs explicit owner sign-off. Regenerate the
installed-package summary with `npm run licenses` (`--all` for the full list).

BSD-3-Clause 1, CC-BY-4.0 1 (data package, dev-only). No GPL/LGPL/AGPL.

## Redistribution and fixture policy
* No third-party image fixtures are committed in M1–M2; all test images are generated by
  the tests (procedural). When real fixtures are added (M4/M8) each gets a
  `fixtures/LICENSE-<name>.txt` provenance record; only CC0/PD/self-authored content.
* No Adobe SDK, no Adobe assets, icons or fonts. UI glyphs are original inline SVG.
* Fonts: only system fonts are referenced by name; none bundled yet.

## Known risks
* Electron 45 requires Windows 10+ x64/arm64; renderer GPU use depends on user drivers.
* `npm audit` is checked at each milestone; result recorded in HANDOVER.
