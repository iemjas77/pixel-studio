# Pixel Studio

An original raster image editor for Windows (Electron + React + TypeScript). **Engineering preview** – see
[`docs/HANDOVER.md`](docs/HANDOVER.md) for status, launch/build/test instructions, the implemented/partial/planned matrix and
known limits. Specs are in [`docs/`](docs/).

```bash
npm install && npm run build && npm start
npm test            # unit tests
npm run test:e2e    # Electron E2E (needs xvfb on Linux)
```
Not affiliated with Adobe. No Adobe code, assets or branding are used.
